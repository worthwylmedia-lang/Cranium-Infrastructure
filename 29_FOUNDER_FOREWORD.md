# Founder Foreword

Convertible Cranium began with a practical question: how can increasingly capable machine cognition operate inside a system where authority remains explicit, bounded, reviewable, and recoverable?

The answer documented in this binder is not a claim that every mechanism is unprecedented. It is an architectural discipline: cognition can propose, but canonical authority must remain outside cognition and must be issued through a defined authority boundary.

The purpose of this repository is therefore not to ask a reviewer to believe. It is to make the architecture inspectable, the boundaries explicit, the evidence traceable, and the limitations visible.

The historical engineering account remains available for deeper provenance. This clean surface is intended to make the system understandable without requiring a reviewer to reconstruct its architecture from years of development artifacts.

**Wyl Mathes**
Founder, Convertible Cranium

## Current architecture baseline

The canonical authority path is Listener → Engine 1 Synapse → independent Engine 2A Substrate A (Constitutional Authority, “May We?”) and Engine 2B Substrate B (Evidence Grounding, “Is It So?”) → Engine 3 Cranium Kernel convergence → governed execution and receipt/lineage. Cranium AI is a cognition/application surface, not an authority-path engine. Neither substrate grants canonical authority; the Kernel remains the sole canonical authority source.

Commander OS is the operational control surface. Cranium Listener is untrusted ingress. Miracle Memory provides governed continuity. Circuit Breaker / COMA provides cross-cutting runtime containment and recovery. The Convertible Cranium Kernel remains the sole canonical authority source.

The former Eight-Plane and Dual-Engine descriptions are historical framing only and must not be read as the current governance model.
