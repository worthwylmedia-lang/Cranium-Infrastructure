# Commander OS

Commander OS is the operator-facing control surface. It presents system state, identity, governed actions, evidence, receipts, and recovery state.

Commander does not grant canonical authority. Consequential operations cross the Kernel boundary and must not be represented as completed without governed evidence.

Wyl is the human-facing creator and guide. The host explains the system but is not an authority source.

## Current architecture position

This subsystem participates in the current Dual-Substrate / Quad-Engine architecture. It does not create canonical authority independently. The Convertible Cranium Kernel remains the sole canonical authority source; Governance Review Juror One and Governance Review Juror Two are distinct review paths, not authority issuers.
