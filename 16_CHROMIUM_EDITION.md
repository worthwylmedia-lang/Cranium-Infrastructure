# Chromium Edition

Convertible Cranium Chromium Edition is the planned ChromiumOS-derived operating environment that places the governed-intelligence substrate inside a familiar desktop/browser foundation.

## Integration

- ChromiumOS provides the operating-system foundation, browser, windowing, files, settings, hardware integration, and application environment.
- Commander OS provides the governed operator surface.
- Cranium AI provides cognition and orchestration.
- Synapse assesses bounded evidence and trust conditions.
- The Kernel remains the canonical authority boundary.
- Miracle Memory provides governed continuity.
- Circuit Breaker / COMA provides containment and deterministic recovery.

## Boundary

The Chromium Edition is not ChromeOS and should not be presented as an official Google product or as a Google-supported build. ChromiumOS licensing, attribution, trademarks, and third-party component obligations remain applicable to the derived distribution.

The Wyl host is a human-facing guide. It explains the system and its provenance but does not grant authority.

## Build Status

The integration payload and build scripts are staged, but a final bootable ChromiumOS image requires a supported Linux x86-64 build host. Android/Termux is a control surface, not the native ChromiumOS build environment.

Production release claims require reproducible build provenance, image hashing, verified-rootfs or verified-boot configuration as applicable, and runtime boot and acceptance evidence.
