# Cranium AI

Cranium AI is the cognition and orchestration plane. It interprets intent, proposes actions, and coordinates bounded workflows.

AI output is proposal material, never canonical authorization. The model provider supplies cognition; Convertible Cranium supplies the governance boundary.

Distributable artifacts must not contain provider API keys or other secrets.

## Current architecture position

This subsystem participates in the current Dual-Substrate / Quad-Engine architecture. It does not create canonical authority independently. The Convertible Cranium Kernel remains the sole canonical authority source; Governance Review Juror One and Governance Review Juror Two are distinct review paths, not authority issuers.
