# Governed-Intelligence OS Abstract

Convertible Cranium is an infrastructure architecture for governed intelligence in which cognition and canonical authority are deliberately separated.

The system organizes intelligence, evidence assessment, independent governance review, canonical authority, execution, continuity, recovery, constitutional constraints, and verifiable receipts across explicit governed boundaries. Its defining invariant is that non-authoritative signals cannot collectively synthesize canonical authority.

This architecture is intended to support agentic systems and operating environments in which consequential transitions must remain bounded, attributable, replay-resistant, and recoverable.

The Chromium Edition applies this discipline to a ChromiumOS-derived operating environment. Its native image and runtime acceptance remain separate build and validation gates.

## Current architecture baseline

The canonical authority path is Listener → Engine 1 Synapse → independent Engine 2A Substrate A (Constitutional Authority, “May We?”) and Engine 2B Substrate B (Evidence Grounding, “Is It So?”) → Engine 3 Cranium Kernel convergence → governed execution and receipt/lineage. Cranium AI is a cognition/application surface, not an authority-path engine. Neither substrate grants canonical authority; the Kernel remains the sole canonical authority source.

Commander OS is the operational control surface. Cranium Listener is untrusted ingress. Miracle Memory provides governed continuity. Circuit Breaker / COMA provides cross-cutting runtime containment and recovery. The Convertible Cranium Kernel remains the sole canonical authority source.

The former Eight-Plane and Dual-Engine descriptions are historical framing only and must not be read as the current governance model.
